# Security Policy

## Supported Versions

Security fixes are provided for the latest code on `main`. Older commits and
releases are not maintained.

## Reporting a Vulnerability

Email the maintainer at qc815@nyu.edu with a description, affected code, and
steps to reproduce the problem. Do not disclose vulnerabilities or secrets in
public issues or pull requests before a fix is available.

## Security Updates

The maintainer will review reports, coordinate a fix with the reporter, and merge
the fix into `main`. Update to the latest `main` to receive security fixes.
